# Levantamento de requisitos 

## Requisitos funcionais

### RF01
o sistema deve ser capaz de cadastrar usuários com e-mail e senha e eles devem ser capazes de logar no sistema
### RF02
Cadastro de Produtos com nome, descriçao, ID e estoque onde todas estes quisitos possam ser editados e o produto possa ser excluido

### RF03
O sistema deve gerar relatórios diarios,semanais,mensais e anuais com todas as alterações em PDF que possa ser baixado

## Requisitos não funcionais

### RNF01
o tempo de resposta deve ser de até 2 segundos

### RNF02
o sistema deve ser compátivel com todos os navegadores mais utilizados atualmente

### RNF03
o sistema deve funcionar tanto em celular quanto em computador

### RNF04
o sistema não deve disponibilizar senhas e e-mails dos funcionários nem outras informações confidenciais

## Regras de negócio

### RN01
o sistema só deve aceitar e-mails da empresa
